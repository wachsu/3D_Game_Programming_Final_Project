# Mini Project 4.E.3 — Game UI

## 1. Overview

In-game HUD of *Duty Calls: Restroom Rescue*: a **timer bar**, a **rescue list** and a **minimap**, plus level / remaining-count text and centre messages (rescued, level clear, win, time up).

## 2. Scene

**Scene:** `E_GameUI_Demo.unity` (`Assets/_Project/Scenes/Sandbox/MiniProjects_E/`)

Regenerate it from the Unity menu **Game > Build Game UI Demo Scene** (`GameUiDemoSceneBuilder`, which uses `GameHudBuilder`).

## 3. How to Run

1. Open `E_GameUI_Demo.unity` and press **Play**.
2. **WASD** move, **Shift** run, mouse look (click the Game view to lock the cursor, Esc releases it).
3. Walk near an NPC (capsule) and press **E**: Waiting/Wandering → Following; press **E** again: → Arrived (rescued).
4. **K** makes the nearest NPC wander (simulates a child running off).
5. Let the 90 s timer run out → "TIME UP"; rescue all five → "YOU WIN". **Enter** restarts.

## 4. Implemented Features

- **Timer bar** (`TimerBar`): fill = remaining time, colour fades green → yellow → red, pulses below 25 %, `mm:ss` label.
- **Rescue list** (`RescueListPanel`): one row per `IRescueTarget` (name, type, state); state colour changes, rescued rows are struck through.
- **Minimap** (`MinimapView`): top-down orthographic camera rendered to a `RenderTexture`, shown in a circular mask. Player at the centre with a facing indicator; NPC dots coloured by type; NPCs outside the range stick to the edge (dimmed); rescued NPCs disappear.
- **HUD controller** (`GameHud`): reads only `IGameStatus`, `IRescueTarget` and `GameEvents`, so it works with the real GameManager and NPCs without referencing their classes.
- **Demo scene** is generated by code: 36 obstacles in a loop, 5 demo NPCs.

## 5. New vs Reused

**New (written for this mini project):** `GameHud`, `TimerBar`, `RescueListPanel`, `MinimapView`, `IGameStatus`, `GameHudBuilder`, `GameUiDemoSceneBuilder`, `DemoRescueNpc`, `GameUiDemoDriver`.

**Reused:** `GameEvents`, `IRescueTarget`, `NpcType`, `RescueState` (Core interfaces); Player prefab, `PlayerMotor`, `ThirdPersonCameraInput` and the *Setup Third Person Camera* tool (mini project 4.A.2); Unity built-in UI sprites and TextMeshPro.
